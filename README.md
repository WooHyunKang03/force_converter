# 공학용 힘 단위 변환기

## 업데이트 항목

- `force_converter_10.07.py`로 힘 단위 변환 GUI를 실행할 수 있습니다.
- `load_analyzer.py`가 `load_data.csv`의 `time_s`, `force_N` 데이터를 분석합니다.
- 단면적 `100 mm²`를 기준으로 `stress_MPa` 열을 계산해
  `load_result.csv`에 저장합니다. 원본 CSV는 수정하지 않습니다.
- 데이터 개수, 최대 하중과 해당 시간, 최대 응력과 해당 시간을 출력합니다.
- 시간-응력 그래프를 점과 선으로 표시해 `stress_plot.png`로 저장합니다.
  그래프에는 최대 응력, 기준 응력 `6 MPa`, 기준 초과 데이터 개수가 표시됩니다.
- `time_s` 또는 `force_N`이 비어 있거나 숫자가 아닌 행은 원본 CSV 행번호와
  문제값을 출력하고 분석에서 제외합니다. 유효한 데이터가 없으면 계산을
  중단합니다.
- 분석에 필요한 외부 패키지는 `pandas`와 `matplotlib`입니다.

### 하중 데이터 분석 실행

```powershell
.\.venv\Scripts\python.exe .\load_analyzer.py
```

분석 결과 파일:

- `load_result.csv`: 유효한 하중 데이터와 `stress_MPa`
- `stress_plot.png`: 시간-응력 그래프

## 프로그램 용도

`force_converter_10.07.py`는 입력한 힘의 크기를 다른 힘 단위로 변환하는
데스크톱 GUI 프로그램입니다.

입력 단위를 제외한 나머지 지원 단위로 변환한 결과를 표시합니다.

지원 단위는 다음과 같습니다.

- `N`
- `kN`
- `kg`
- `kgf`
- `ton`

프로그램에서는 다음 환산값을 사용합니다.

- `1 N = 1 N`
- `1 kN = 1000 N`
- `1 kg = 9.80665 N`
- `1 kgf = 9.80665 N`
- `1 ton = 9806.65 N`

## 실행 명령

명령 프롬프트 또는 PowerShell에서 Python 파일이 있는 폴더로 이동한 뒤
다음 중 하나를 실행합니다.

```powershell
python force_converter_10.07.py
```

또는 Windows Python 런처를 사용하는 경우:

```powershell
py force_converter_10.07.py
```

실행하면 `공학용 힘 단위 변환기` 창이 열립니다.

## 필요한 환경

- Python 3.9 이상
  - 소스 코드에서 `list[...]`, `tuple[...]` 형식의 타입 표기를 사용합니다.
- Python 표준 라이브러리의 Tkinter
  - `tkinter` 및 `tkinter.ttk`를 사용해 GUI를 표시합니다.
- 별도로 설치해야 하는 외부 Python 패키지는 코드에서 확인되지 않습니다.

사용 중인 Python 배포판에 Tkinter가 포함되어 있지 않으면 GUI를 실행할 수
없습니다. 이 파일만으로 운영체제별 Tkinter 설치 방법은 확인할 수 없으므로
별도의 설치 명령은 제시하지 않습니다.

## 사용 방법

1. 프로그램을 실행합니다.
2. `힘의 크기` 입력란에 숫자만 입력하거나 숫자와 단위를 함께 입력합니다.
3. 숫자만 입력한 경우에는 아래 단위 선택 상자에서 입력 단위를 선택합니다.
   기본 선택 단위는 `N`입니다.
4. `변환` 버튼을 클릭하거나 입력란에서 `Enter` 키를 누릅니다.
5. 입력 단위를 제외한 단위별 변환 결과를 확인합니다.
6. `결과 복사` 버튼을 누르면 표시된 변환 결과를 클립보드에 복사합니다.
7. `초기화` 버튼을 누르면 입력란, 선택 단위, 결과 표시가 기본 상태로
   돌아갑니다. 최근 입력 기록은 유지됩니다.

단위가 포함된 입력은 대소문자를 구분하지 않습니다. 예를 들어 `1kg`,
`1KG`, `1 kg`은 같은 단위 입력으로 처리됩니다.

최근 입력 기록은 최대 10개까지 표시됩니다. 기록 항목을 클릭하면 해당
입력을 다시 변환할 수 있습니다.

## 정상 입력 예시

### 숫자만 입력하는 경우

단위 선택 상자에서 `N`을 선택한 상태로 다음과 같이 입력합니다.

```text
1000
```

변환 결과는 다음과 같이 표시됩니다. 결과값은 소수 셋째 자리까지
표시됩니다.

```text
1.000 kN
101.972 kg
101.972 kgf
0.102 ton
```

### 숫자와 단위를 함께 입력하는 경우

```text
1kg
```

또는 다음처럼 숫자와 단위 사이에 공백을 넣을 수 있습니다.

```text
1 kg
```

결과는 다음과 같이 표시됩니다.

```text
9.807 N
0.010 kN
1.000 kgf
0.001 ton
```

과학적 표기법과 부호가 포함된 숫자도 입력 형식에 맞으면 사용할 수
있습니다. 예시는 다음과 같습니다.

```text
-2.5e3 N
```

## 오류 입력 예시

### 숫자 형식이 아닌 입력

```text
abc
```

다음 오류 메시지가 표시됩니다.

```text
오류: 숫자만 입력하거나 숫자와 단위를 함께 입력해 주세요. 예: 1 또는 1kg
```

### 지원하지 않는 단위

```text
1lb
```

다음 오류 메시지가 표시됩니다.

```text
오류: 지원하지 않는 단위입니다. N, kN, kg, kgf, ton 중 하나를 사용하세요.
```

### 계산할 수 없을 정도로 큰 값

```text
1e309
```

다음 오류 메시지가 표시됩니다.

```text
오류: 연산이 불가능하거나 너무 큰 값입니다.
```

## 참고

- 변환 결과는 입력 단위를 제외하고 표시됩니다.
- 변환 결과는 파일로 저장되지 않으며, `결과 복사` 버튼으로 클립보드에
  복사할 수 있습니다.
